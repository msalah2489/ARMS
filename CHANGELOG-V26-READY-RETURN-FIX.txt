ARMS V26 - Ready Return Fix

Fix: devices that completed maintenance were not appearing under
"أجهزة جاهزة للإرسال للفرع".

Root cause:
The ReadyToReturn filter incorrectly required SentAt == null.
SentAt was already populated when the branch originally sent the device
to maintenance, so repaired devices were excluded from the ready-to-return list.

Changes:
1. Removed SentAt == null from the supervisor ready-to-return query.
2. Removed the same incorrect condition from same-request readiness checks.
3. A device is now considered ready to return based on its actual current state:
   - CurrentLocation = مستودع الأجهزة الجاهزة للإرجاع
   - CurrentStatus = جاهز للإرسال
   - Not paused
   - Not excluded/scrapped/replaced
   - Not assigned to a technician
