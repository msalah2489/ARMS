ARMS V2.4.15 - Consolidated Requested Changes

- Global customer search remains system-wide; request remains branch-owned.
- Added customer device receipt records linked to individual devices, allowing the same receipt number/image to be used for multiple devices and multiple delivery receipts over time.
- Added service type to requests, including diffuser-device maintenance.
- Added responsive mobile layout improvements.
- Added spare-part code field and stock sorting/filtering.
- Added spare-part receiving slips with mandatory slip number/image and stock movement ledger.
- Added combined spare-part movement reporting for receipts, consumption, and recovery, with Excel export.
- Added replacement warehouse model/status filters, replacement status, and scrap flow that can recover selected spare parts into stock as a distinct movement type.
- Added maintenance-center flag to branches and maintenance-center assignment for maintenance technicians/supervisors; edits change future assignment without rewriting historical operations.
- Prevented central-dispatch selection for devices routed to local maintenance.
- Preserved per-device route behavior for mixed requests.
- Preserved non-repairable workflow: technician reports non-repairable -> supervisor decision (return to technician / replacement / return to branch without repair).
- Improved customer receipt visibility in device history.
- Kept previous QR/device-history, bulk dispatch, reports, technician monitoring, and permissions changes from prior versions.
