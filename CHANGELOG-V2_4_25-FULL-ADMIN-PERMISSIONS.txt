ARMS V2.4.25 — FULL ADMIN PERMISSIONS

- مدير عام ARMS is treated as the IT/System Administrator (Super Admin), equivalent to the legacy مدير رئيسي role.
- Centralized system-admin role detection in ArmsAuth.IsSystemAdminRole().
- Enabled system-admin access to admin-only pages including replacement warehouse, spare-part receiving, spare parts/inventory, device catalog/accessories, diagnostic guide administration, technicians, shipping, device history corrections, settings, and related reports.
- Enabled system-admin access to the standard service-request creation page.
- Added branch selection for system-admin when creating a standard service request; branch users continue to use their assigned branch.
- Added the standard service-request button to the home page for system admin.
- System-wide home statistics and recent requests are shown to system admin.
- Existing audit fields continue to use the authenticated user's FullName, so actions by the system-admin account are recorded under the actual account name.
- Preserved previous workflow-integrity changes.
- Build was not executed in the creation environment because dotnet is unavailable there; local build verification is required.
