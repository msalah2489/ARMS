# نموذج ARMS التجريبي (تفاعلي)

نموذج HTML عربي RTL لمحاكاة أدوار ومسارات نظام ARMS ببيانات وهمية — **ليس** التطبيق الحقيقي.

## كيف تفتحه؟

1. افتح المجلد:
   `C:\Users\user\ARMS\docs\mockups\arms-prototype\`
2. انقر مرتين على الملف `index.html`  
   أو اسحبه إلى نافذة المتصفح (Chrome / Edge / Firefox).
3. يعمل عبر `file://` بدون خادم.

اختياري: من مجلد المشروع شغّل خادماً بسيطاً ثم افتح الرابط، مثلاً:

```bash
npx --yes serve docs/mockups/arms-prototype
```

## ماذا تجرب؟

بدّل **الدور** من القائمة أعلى الصفحة:

| الدور | ماذا يعمل؟ |
|--------|------------|
| موظف فرع | التبويبات الخمسة + استلام من العميل + إرسال للصيانة (مندوب/بوليصة) + استلام من الصيانة ثم تسليم للعميل |
| مندوب استلام | الموافقة/الرفض على نماذج الاستلام |
| فني | طابور الأجهزة + سحب + إكمال/تعذّر |
| مشرف صيانة | قرارات معلّقة + قسم الشحن |
| مدير صيانة | نفس لوحة القرار مع نظرة على الأجهزة المعلّقة + الشحن |

الأعداد والحالات تتحدث عند الضغط على الأزرار. البيانات تُحفظ في المتصفح (`localStorage`). زر **إعادة بيانات** يعيد الحالة الافتراضية.

## ملفات

- `index.html` — الصفحة
- `styles.css` — الألوان (رمل/حبر) والتنسيق
- `app.js` — المنطق والبيانات التجريبية
